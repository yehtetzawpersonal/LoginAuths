# Login Authentication System

A simple login authentication system built with **Spring Boot**, **MyBatis**, **Thymeleaf**, and **Oracle Database**.  
This project supports user registration, login, logout, forgot password, and password reset via email, and Google OAuth2 login.

---

## 📌 Features

- User registration with email and password
- Login authentication with encrypted passwords (BCrypt)
- Session-based login management
- Forgot password functionality
- Password reset via email link (token-based)
- Token expiration handling
- Login with Google (OAuth2)
- Form validation (frontend and backend)

---
